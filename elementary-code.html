エレメンタリーコード（Elementary Code）について

パスワードレス・ナンバーレス・個人情報登録不要。

Tandem AIR System で用いる識別の枠組みです。事前設定したパスワードや認証番号は使わず、ユーザー同士および設定した他社アプリとの接続直前に、Elementary Code がその都度即時認証します。内部では親コードや識別コードを使いますが、ユーザーに番号の記憶や入力は求めません。

コード本体をユーザー向けに晒す運用は行いません。

生活・防犯での想定用途

  • 通話前の本人確認（なりすまし・フィッシング対策の補助）
  • SNS・DM からの誘導に対する注意喚起（特殊詐欺・闇バイト等）
  • 旅先・日常のつながり（相手を確認してからつなぐ）
  • Apple 審査・サポートで説明する公開情報との整合

通話前認証

通話前認証システムにより、発信・着信の際に、あなたより先に、すべて自動で相手の本人確認を瞬時に行います。

エレメンタリーコードとは

ビットコインよりも一意性が高く保たれる、独自開発のコード「エレメンタリー・パーティクル」（素粒子を思わせる要素）を、認証の場面から「エレメンタリーコード」と呼んでいます。そのコードがあることで、多要素認証の確認ができます。

DNA や指紋は一意性に優れますが、これは遥かに高い、素粒子のような存在として設計しています。そのため、電話番号もパスワードも必要としません。

速度が条件

どれほど複雑でパスワード的な要素が強くなっても、確認に暗号資産・ビットコイン1枚あたり約10分のような時間がかかるなら、電話の認証としては使えません。短時間で確認を完了させることを目標にしなければ、通信で使えない——そう理解しました。

偶然のように開発された「エレメンタリーコード」では、認証確認は約1秒程度で完了します。特に海外では、Air アプリが直接認証を行う方法とは異なり、現行キャリア発信と比べると、通話が開始されるまでの時間差がより大きく感じられると思います。

1対1の限定回線

通話は発信と受信それぞれ専用設計です。Air 通信限定接続に加え、1セットのペアでしか接続できない構造のため、なりすましや第三者の割込み、コピーも想定しにくい設計です。SNS のように広がることが目的ではなく、1対1の限定回線として、互いが専用となるイメージで設計しています。

開発の姿勢

「人手不介在」を最低限の義務とし、いつまでも App Store に置いていただけるアプリの開発を目指しています。破損した場合には元に戻せない設計であること、たまたま持っていた方にも役立つ時を想定した無料プランも、原稿どおりの方針です。

操作のやさしさ

長押しするだけで、返信メールと同様の意味で送信できる操作を想定しています。

エレメンタリーコード関連技術：転送・一致照合速度の参考試験

報告日：2026年10月10日

エレメンタリーコードで重要となる「コードの転送」と「一致確認」に関連した基礎動作について、Pythonを用いた簡易ベンチマークの報告数値を掲載します。これは認証システム全体の所要時間ではありません。

報告された参考測定値
対象コード12桁の数字列
処理件数100,000件
総処理時間18.962ミリ秒
平均処理時間0.18962マイクロ秒／件（189.62ナノ秒）
転送後の一致照合100,000件すべて一致
入力の完全重複観測0件
前回報告の参考値総時間18.113ミリ秒・平均約0.181マイクロ秒／件

試験方法と数値の意味

Pythonの単一プロセス内で、あらかじめ生成した10万件の12桁コードを配列から別の配列へ順に代入し、代入後の値が元のコードと一致するかを比較します。開始時刻と終了時刻との差を件数で割った数値が、1件当たりの平均処理時間です。コード生成そのものにかかる時間はこの測定に含みません。

0.18962マイクロ秒とは約0.00000018962秒で、今回の条件で行った1件当たりのメモリ内代入と一致比較の平均です。Pythonの文字列参照の代入を含むため、文字列の全バイトを別の端末に転送した速度とは異なります。

一致率と一意性について

一致照合10万件成功は「代入先が元の入力と等しい」ことを確認した結果です。入力の完全重複が0件だったことは、このサンプルに同じ値が見つからなかったことを示します。ただし、今回のコードは実際のエレメンタリーコードの発行方式で生成したものとは限らず、この結果は全コードの重複が絶対に起きないことの証明ではありません。

測定対象に含まれない工程

ネットワーク通信、異なる端末間の送受信、世界時刻の同期、暗号処理、発行管理、本人確認、画面操作、端末間の全認証処理は測定に含みません。今回の測定環境はLinux上のPythonであり、MacおよびiPhone実機での再現試験や、第三者機関による検証を示すものではありません。

技術的な評価：短いコードのメモリ内代入と等値比較が短時間で実施できるという基礎的な目安は得られています。一方、実際の認証速度・安全性・数学的一意性・他方式に対する世界最速の優位性を確定するには、別途それぞれの検証が必要です。公開値は現段階での参考報告値として扱います。
