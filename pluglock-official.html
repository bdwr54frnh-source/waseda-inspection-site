Plug Lockの中核技術

ELEMENTARY CODE — 高速処理と、持ち歩かない新しい鍵

パスワードを決めない。認証用レンズもいらない。個人情報の入力も不要。同じ鍵を持ち歩かない。必要なのはiOS。

ELEMENTARY CODEは、軽快なコード処理と照合を目指す独自技術です。鍵そのものを持ち歩く代わりに、利用者が選んだ更新条件に合わせて新しい認証コードへ切り替える設計を進めています。

鍵の変更頻度は、利用者自身が選択

  • 週に1度 自動更新
  • 月に1度 自動更新
  • 変更したい時に ワンタップで更新

一度設定すれば、更新管理は自動化する構想です。パスワードの作成、カメラ・レンズによる本人撮影、氏名・住所などの個人情報入力を前提とせず、iOSから自分の守り方を管理する設計です。対応範囲と安全性はリリースに向けて検証します。

ELEMENTARY CODE 実験結果

毎秒1,000個のコード生成、毎秒1,000組の認証確認。 特別な性能向上カスタマイズを施さない基本構成で得られた実験結果として報告しています。

iOSのパフォーマンスを活かし、暮らしの安全を支えるパートナーへ。 安定して確かな認証結果を届けることを目標に、日常で使い続けられるセキュリティを開発しています。

上記の処理件数と構成条件は事業者報告による実験値です。長期間の安定稼働、あらゆるiOS端末での性能、実運用環境での認証成功率を保証する値ではなく、今後の検証対象です。

これらの結果について、弊社調査では同様の事例を確認できていません。 また、関連内容は特許文献調査として特許庁に提出済みとの報告です。

上記の毎秒値・提出状況は事業者申告によるもので、当ページ制作時点で実験ログや提出控えとの独立照合は未実施です。「同様の事例を確認できない」は世界初・最速や特許性が公的に認められたことを意味せず、提出済みも特許の取得・審査承認を意味しません。

処理速度の参考試験

参考試験では、30桁のコード10万件のメモリ内代入・照合に合計14.567ミリ秒、平均0.14567マイクロ秒／件を記録しました（25桁：10万件で14.302ミリ秒）。

この数値は参考環境でのメモリ内処理速度です。ネットワーク接続を含む実際の認証時間や、認証システム全体の処理速度を実測した値ではありません。製品化に向けた実機検証を継続します。

長く安定して使い続けられる仕組みを目指して設計しています。「半永久的」は製品寿命や安全性を保証する意味ではありません。 長期継続運用・認証の安定性については検証中です。

2026年10月10日実験（Python 3.13.5 / Linux）：25桁と30桁、それぞれ10万件の同一プロセス内の参照代入・一致比較を実施。25桁は14.302ミリ秒（平均0.14302マイクロ秒／件）、30桁は14.567ミリ秒（平均0.14567マイクロ秒／件）。両方とも10万件一致し、各入力の重複は観測0件でした。

30桁の平均値から計算上は毎秒約686万件のメモリ内代入・一致比較に相当します。ただし生成時間・通信・暗号認証・端末間の確認は含まれません。

有料版・開発中

Plug Lock REVOLVER — 人手非介在の鍵

鍵の組み合わせは「無限通り」を目指す設計思想。その広大な組み合わせの中から、毎秒1,000の新しい鍵を生成し、鍵の変更時にランダムに選択する構想です。

「無限通り」は設計理念を示す表現で、数学的に無限の鍵空間が実証されたという意味ではありません。生成速度・ランダム性・安全性は製品実装で検証する必要があります。

人手非介在の鍵が切り開く未来

鍵を作り、交換し、管理するために人の手を必要としてきた長い歴史。私たちは、鍵そのものを新しく生成・更新し、利用者が決めた条件のもとで自動管理する仕組みに挑戦しています。

従来の玄関には鍵穴があり、物理的な攻撃の対象にもなり得ます。将来は鍵穴のない玄関へ。大きなガラスの玄関がシャッターのように天井へ収納され、車と一緒に住まいへ入る。ITと建築が手を取り合い、未来のドアが開く瞬間に輝き始める——そんな住宅の可能性を描いています。

これは将来構想であり、住宅設備・車両との連携や製品化が実現済みという意味ではありません。

AIR専用公式サイト｜Plug Lock

みんなで育てる公式アドレス帳。なりすましに気づくための、新しい確認方法。

なりすましに関する情報が増える中、業界や店舗の公式サイトを確認しやすくする共有アドレス帳を準備しています。公式サイトをタップして開き、好きな部分を専用スキャンで撮影。ガラスアイコンに取り込み、専用ホルダーで管理する仕組みです。

ご利用の流れ（開発予定）

  1. 公式サイトを選ぶ：アドレス帳に掲載された店舗・業界の公式サイトをタップして開きます。
  2. ガラスアイコンにする：表示されたサイトの好きな部分を専用スキャンで撮影してタップし、ガラスアイコンからホルダーへ保存します。
  3. 着信時に確認する：アプリが取得できる着信・連絡先情報と登録済みの公式情報を照合し、確認結果を光で知らせる機能を目指します。注意が必要な場合は黄色く点滅する設計です。
  4. 情報を追加・更新する：店舗名とURLを入力して登録候補を送信。公式性の確認ができた場合に掲載し、その後も定期的に再検査します。

この公式アドレス帳は、利用者からの新しい情報提供も受けながら、みんなで育てていく共有サービスを目指しています。掲載前の自動検査と、掲載後の定期的な再確認を予定しています。

開発状況：専用スキャン、ガラス化、ホルダー保存、投稿・審査、公式サイトの自動検査、着信の先行検知、発光・黄色点滅通知、定期更新は開発予定の機能です。このページ上で現在利用できる機能ではありません。iOSの着信情報へのアクセスには制限があり、実現可能な照合方法を検証します。公式サイトの掲載や一致表示だけで、電話・メールの発信元の正当性、安全性を保証するものではありません。
